# Steps for First Pull
### *After first pull, these steps can be discarded.
1. Install [git](https://git-scm.com/install/) to your system.
2. Open **Command Prompt**. Type and run in this line of code, and replace `path` with your `xampp/htdocs` path.

cd path

3. Go to [your project page](https://github.com/JoeMama730/projeksk2026), and click on the **green Code** button. Select **HTTPS** and copy the link.
3. Go back to your command prompt, it should say `C:\xampp\htdocs` or something similar, at the front. Type and run in this line of code, and replace `web_url` with the link that you have copied.

git clone web_url

4. Open your project from the `htdocs` folder to **Visual Studio Code** and begin making your changes.

# Steps for Future Pulls & Pushs
1. Committing & Push:
    - After making changes to your project (at school/at home), make sure to **commit** your changes to GitHub. You can do this by going to the **Source Control** section and click "**Commit**".
    - Click on the **+** icon next to your file change to add it to "**Staged Commits**" before you commit.
    - Type in your **commit message** based on the changes you have made. (e.g. _Styling changes_)
    - Push your changes by clicking on "**Sync Changes**" or the "**Push**" button on the three dots.
    - Go back to [your project page](https://github.com/JoeMama730/projeksk2026), and check to see if your changes were pushed.

2. Pulling:
    - If you had done changes at school and you wanted your changes back at home, it needs to undergo **pulling**.
    - To do so, at home/school, go to **Visual Studio Code** and click "**Pull**" on the 3 dots.
